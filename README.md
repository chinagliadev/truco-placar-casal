# Truco Placar Casal

Projeto simples de jogo/tracker de placar de Truco, ideal para praticar **HTML**, **CSS** e **JavaScript**.

---

## :gear: Tecnologias utilizadas
- **HTML** — estrutura básica das páginas  
- **CSS** — estilização dos elementos (conteúdo em `css/`)  
- **JavaScript** — lógica interativa (códigos dentro de `js/`)

---

## :open_file_folder: Estrutura do repositório

- `index.html` — página principal com o placar interativo  
- `css/` — arquivos de estilo para layout e design visual  
- `js/` — scripts JavaScript que controlam o funcionamento do placar  
- `img/` — possíveis imagens utilizadas na interface (se houver)

---

## :dart: Objetivo do projeto

Criar um placar funcional para acompanhar partidas de Truco entre casais, aplicando e reforçando conhecimentos de:

- Manipulação de DOM em JavaScript  
- Eventos e interatividade (botões para incrementar contagem, reset, etc.)  
- Layout responsivo e visual agradável com CSS
